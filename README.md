# MacMCMD
MacOS Mobile Client Management Direct-editor; for directly editing settings variables on provisioned MacOS laptops.
## What does it do?
It allows school/work-provisioned laptops to use personalization settings frequently disabled. Think wallpapers and color settings. MMCMD only generates long strings of commands to use in Terminal. It isn't an app and does not need admin access, but it does require using Terminal.
